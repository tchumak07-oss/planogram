🏬 Точки продажу

Список твоїх точок продажу. Можна додати вручну або завантажити таблицею (Excel/CSV, колонки: Назва, Адреса, Телефон, PIN — колонка PIN необов'язкова, але якщо є, код доступу для магазину встановиться одразу під час імпорту).

🔗 QR-код для входу

⚠️ Збережи або роздрукуй це зараз — після закриття вікна PIN у відкритому вигляді більше ніде не показується.

📌 Опублікувати для точки

Точка продажу побачить саме той стан полиць (розкладку, назви, фото), який зараз тут відкритий, — у режимі перегляду. Каталог товарів спільний для всіх.

📊 Аналіз фото-звітів

Показує, скільки фото завантажила кожна точка продажу за обраний період — і хто ще не здав звіт.

📷 Фото-звіти

Завантаж фото реальної вітрини по точках продажу (наприклад, для звітності чи перевірки виконання планограми).
